\# DoctorPro - Premium Doctor Website \& Frontend Admin Panel



DoctorPro is a commercial-grade, fully responsive doctor personal portfolio website featuring a pure frontend CMS Admin Panel, built using \*\*HTML5, CSS3, and Vanilla JavaScript only\*\*. No backend, database, or server installation is required.



\## 🚀 How to Run the Website

1\. Extract the `doctorpro` ZIP folder.

2\. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari).

3\. To access the Admin Panel, click the \*\*Admin Panel\*\* button in the top navigation or open `admin.html`.



\## 🛠️ Features

\- \*\*Pure Frontend Architecture:\*\* Runs entirely in the browser using `localStorage`.

\- \*\*Dynamic Theme Customizer:\*\* Modify primary colors and backgrounds with live UI updates.

\- \*\*Bilingual Language Support:\*\* Instant toggle between English and Bangla.

\- \*\*Frontend Appointment System:\*\* Patients can submit appointment requests stored locally.

\- \*\*Protected Developer Branding:\*\* Permanently displays \*\*Dream Career IT BD\*\* attribution without exposing it to editable CMS settings or JSON imports.
